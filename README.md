# iOS Password Manager AutoFill bug demo

Minimal UIKit app with a single blank view controller, for reproducing an iOS Password Manager AutoFill bug.

## Open in Xcode

Open `AutoFillBugDemo.xcodeproj` in Xcode 26, select an iPhone simulator, and run.
